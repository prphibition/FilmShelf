# FilmShelf

**Настольная фильмотека: каталог из ~42 000 фильмов, сериалов, дорам и аниме с русскими названиями и постерами, личным списком просмотра, оценками и отзывами.**

Приложение работает на вашем компьютере, без сервера и аккаунтов в интернете: данные хранятся в одном файле SQLite. Написано на Python с графическим интерфейсом Tkinter, учебный проект (курсовая работа).

## Возможности

- **Каталог и поиск.** Поиск по мере ввода по названию (русскому, оригинальному и английскому), стране, году, жанрам и описанию; фильтры по типу, жанру, стране, годам и рейтингу; сортировка; постраничный вывод. Выборки по каталогу из десятков тысяч записей занимают миллисекунды.
- **Русские названия и постеры.** Для каждого тайтла приложение само подтягивает русское название, описание и оригинальный постер из **Википедии** (без ключа) и **TMDB** (с бесплатным ключом). В таблице результатов видны миниатюры постеров. Если русского названия нигде нет, оно записывается кириллицей по транскрипции.
- **Личный список.** Статус просмотра, оценка и прогресс по сериям для каждого тайтла, фильтры по статусу, статистика профиля, экспорт списка в CSV.
- **Рейтинг.** Взвешенный (байесовское сглаживание): тайтл с одной оценкой не обгоняет тайтл с сотней.
- **Отзывы** пользователей к тайтлам.
- **Роли.** Пользователь и администратор; администратор добавляет, изменяет и удаляет тайтлы и их постеры.
- **Безопасность.** Пароли хранятся только в виде хэша PBKDF2-HMAC-SHA256 с индивидуальной солью и 600 000 итераций; SQL-запросы параметризованы.

## Быстрый старт

Нужен **Python 3.10 или выше** с Tkinter (в Windows и macOS он входит в установщик с python.org; в Ubuntu и Debian: `sudo apt install python3 python3-tk`).

```bash
git clone https://github.com/ВАШ_ЛОГИН/FilmShelf.git
cd FilmShelf
python -m pip install Pillow
python run.py
```

При первом запуске создаётся база и импортируется каталог (несколько секунд). Вход для знакомства: `demo` / `demo1234` (пользователь) и `admin` / `admin123` (администратор). Все данные лежат в папке `.filmshelf` в домашнем каталоге; чтобы начать с чистого листа, закройте приложение и удалите её.

`Pillow` нужна только для постеров; без неё приложение запускается на одной стандартной библиотеке.

## Русские названия и постеры

Всё происходит автоматически, пока приложение открыто:

1. Тайтлы, показанные в результатах поиска, обрабатываются **первыми**, и строки обновляются на глазах.
2. Затем остальной каталог догружается в фоне. Весь каталог занимает порядка часа и около 1,5 ГБ на диске (`~/.filmshelf/posters`); процесс можно прерывать, прогресс сохраняется.
3. Прежнее английское название остаётся «оригинальным», поэтому тайтл находится и по английскому, и по русскому названию.

**Ключ TMDB необязателен**, но с ним постеров и названий будет больше. Получить его бесплатно: [themoviedb.org](https://www.themoviedb.org/) → профиль → Настройки → API. Вставьте его в окне «Русские названия и постеры…» в приложении или задайте переменную окружения `TMDB_API_KEY`. Ключ хранится только на вашем компьютере (`~/.filmshelf/settings.json`) и в репозиторий не попадает.

Автозагрузку можно выключить флажком под таблицей. Ручной запуск из консоли:

```bash
python tools/enrich_from_tmdb.py --limit 2000
```

## Структура проекта

```
run.py                точка входа
filmshelf/
  config.py           настройки и константы
  models.py           модели предметной области
  security.py         хэширование паролей
  database.py         схема SQLite и подключение
  repository.py       слой доступа к данным (все SQL-запросы)
  services.py         бизнес-логика: вход, поиск, список, отзывы, статистика
  catalog_import.py   импорт каталога при первом запуске
  posters.py          работа с постерами и миниатюрами
  enrich.py           загрузка названий и постеров (TMDB) и фоновый загрузчик
  wiki.py             загрузка названий и постеров из Википедии
  translit.py         запасная транскрипция названий
  ui/                 окна и вкладки Tkinter
tools/                сборка каталога, загрузка постеров, снимки экрана
tests/                модульные тесты и сценарии интерфейса
```

Архитектура многослойная: интерфейс → сервисы → репозитории → SQLite. SQL есть только в репозиториях, бизнес-правила только в сервисах.

## Тесты

```bash
python -m unittest tests.test_filmshelf tests.test_enrich   # 65 модульных тестов, интернет не нужен
python -m unittest tests.ui_smoke                           # сценарии интерфейса (нужен экран)
```

Обращения к TMDB и Википедии в тестах проверяются на локальных HTTP-серверах, имитирующих их API.

## Источники данных и лицензии

- Каталог собран из открытых наборов данных о фильмах и сериалах (описание сборки: `tools/build_catalog.py`). Прежде чем использовать данные вне личного проекта, проверьте лицензии исходных наборов.
- Русские названия, описания и постеры загружаются из Википедии (тексты распространяются по лицензии CC BY-SA, изображения: по условиям их страниц на Wikimedia) и TMDB. *This product uses the TMDB API but is not endorsed or certified by TMDB.* Загруженные постеры хранятся только на вашем компьютере и в репозиторий не входят.
- Демонстрационные постеры взяты из открытого набора на GitHub; их автор указан в курсовой работе.
